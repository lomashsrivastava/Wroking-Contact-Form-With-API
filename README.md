# Working Contact Form with API

A responsive and functional contact form built with HTML and CSS, integrated with the [Web3Forms](https://web3forms.com/) API for seamless email submissions without a backend server.

## 🚀 Features

-   **Modern UI/UX**: Clean and responsive design that looks great on all devices.
-   **Functional Backend**: Powered by Web3Forms API to send emails directly from the form.
-   **Validation**: Required fields validation (HTML5).
-   **Custom Styling**: Styled with vanilla CSS for a lightweight footprint.
-   **Success Redirection**: Compatible with Web3Forms success pages.

## 🛠️ Technologies Used

-   **HTML5**: Structure and semantics.
-   **CSS3**: Styling, Flexbox layout, and responsiveness.
-   **Web3Forms**: Form backend API service.

## ⚙️ Setup & Usage

1.  Clone this repository:
    ```bash
    git clone https://github.com/lomashsrivastava/Wroking-Contact-Form-With-API.git
    ```
2.  Open `index.html` in your browser to view the form.
3.  To use your own API key:
    -   Go to [Web3Forms](https://web3forms.com/) to render your access key.
    -   Open `index.html` and replace the value in the hidden input field:
        ```html
        <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY_HERE">
        ```
